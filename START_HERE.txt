E-COMMERCE PURCHASE PREDICTION — QUICK START

1. Extract the ZIP and open the ecommerce_purchase_prediction_project folder in VS Code.
2. Open Terminal -> New Terminal.
3. (Recommended) Create a virtual environment:
   python -m venv .venv
   .venv\Scripts\activate
4. Install packages:
   python -m pip install --upgrade pip
   pip install -r requirements.txt
5. Start the website using the included trained model:
   streamlit run app.py
6. To rerun data cleaning, 3-fold cross-validation, grid search and evaluation:
   python train.py
   Then refresh/restart the website.
