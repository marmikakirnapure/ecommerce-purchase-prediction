# E-Commerce Purchase Prediction Using Machine Learning

A course mini-project that predicts whether an online shopping session ends in a purchase using the UCI Online Shoppers Purchasing Intention Dataset.

## Exactly four models
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest

These are all among the algorithms listed as examples in the course's Machine Learning Lab mini-project instructions.

## Features
- Exploratory data analysis and data-cleaning summary
- Exact duplicate check/removal
- Stratified 80:20 train/test split
- Numeric scaling and categorical one-hot encoding inside pipelines
- Three-fold stratified cross-validation and grid search for each model
- Metrics: accuracy, purchase-class precision/recall/F1, ROC-AUC and average precision
- Confusion matrix, ROC curve, class-distribution and model-comparison figures
- Streamlit UI with prediction and model comparison tabs

## Dataset
The supplied `data/online_shoppers_intention.csv` is included in this project.
Dataset source: UCI Machine Learning Repository, Online Shoppers Purchasing Intention Dataset.
https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset

Citation:
Sakar, C. & Kastro, Y. (2018). *Online Shoppers Purchasing Intention Dataset*. UCI Machine Learning Repository. https://doi.org/10.24432/C5F88Q

## Run on Windows using VS Code
1. Extract the ZIP.
2. Open the extracted `ecommerce_purchase_prediction_project` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Create and activate a virtual environment:

   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   ```

5. Install packages:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

6. The ZIP includes an initial trained model and its result figures, so you can start the app immediately. To rerun data cleaning, tuning, and evaluation on your machine (may take a few minutes), run:

   ```powershell
   python train.py
   ```

7. Start the web app:

   ```powershell
   streamlit run app.py
   ```

8. The browser should open the local application, usually at `http://localhost:8501`.

## Methodological notes
- The dataset has an imbalanced target: purchases are the minority class. Do not interpret accuracy alone.
- Exact duplicate rows are checked and removed; the file is also checked for missing values.
- The target is `Revenue`, converted to 0/1.
- `PageValues` is excluded from predictors because it can be closely associated with completed transactions. Discuss this choice as a leakage-risk precaution in the report.
- Preprocessing is fitted inside pipelines, within each cross-validation fold.
- Hyperparameters are selected on training data using mean 3-fold cross-validation F1-score. The held-out test set is used for final reporting.
- The included metrics and model were generated by running `train.py` on the supplied CSV. Re-run the script if you change the data or code; do not invent or manually alter performance values.
- The app is a demonstration using session-level attributes; it is not a guarantee of actual customer behaviour or a validated real-time production system.
